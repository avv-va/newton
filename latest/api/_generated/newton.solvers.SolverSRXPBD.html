newton.solvers.SolverSRXPBD#

class newton.solvers.SolverSRXPBD(model, *, iterations=2, soft_contact_relaxation=0.9, shape_matching_relaxation=1.0, enforce_momentum_conservation=True, inertia_regularization=0.0, enable_restitution=False, deterministic=None)[source]#

Bases: SolverBase

Shape-matching rigid solver for particle-represented rigid bodies.

Each rigid body is a particle group – a set of particles sharing an entry in newton.Model.particle_group, as produced by add_particle_volume(). Every solver iteration resolves particle-shape and inter-group particle-particle contacts, restores the body’s rigidity with a shape-matching projection, and then removes the momentum that projection introduced.

Rigidity is enforced against a rest shape captured from newton.Model.particle_q when the solver is constructed, so the model must already hold the desired world-space packing at that point. Use set_rest_shape() to re-capture it later.

References

  • Matthias Mueller, Bruno Heidelberger, Matthias Teschner, and Markus Gross. 2005. Meshless deformations based on shape matching. ACM Trans. Graph. 24, 3, 471-478. https://doi.org/10.1145/1073204.1073216

Limitations:

  • Particles only. Springs, cloth bending, FEM tetrahedra, joints, rigid-body integration and rigid-rigid contacts are not simulated; rigid bodies act purely as colliders. Pair this solver with SolverMuJoCo or SolverFeatherstone for scenes that also contain articulated bodies.

  • Shape matching and momentum conservation ignore ParticleFlags, so every particle of a group participates regardless of whether it is active. Contact solving does honour the flags.

  • Groups whose particles are collinear (including single-particle groups) have a singular inertia tensor, and their angular momentum correction is dropped unless inertia_regularization is set.

  • Not differentiable: the momentum-conservation pass updates positions and velocities in place.

  • PROXY solver coupling is not supported.

Example

solver = newton.solvers.SolverSRXPBD(model, iterations=10)

for _ in range(100):
    state_in.clear_forces()
    contacts = model.collide(state_in)
    solver.step(state_in, state_out, control, contacts, dt)
    state_in, state_out = state_out, state_in
__init__(model, *, iterations=2, soft_contact_relaxation=0.9, shape_matching_relaxation=1.0, enforce_momentum_conservation=True, inertia_regularization=0.0, enable_restitution=False, deterministic=None)#

Initialize the shape-matching rigid XPBD solver.

Parameters:

  • model (Model) – Simulation model to integrate.

  • iterations (int) – Number of constraint-solver iterations per time step. Defaults to 2.

  • soft_contact_relaxation (float) – Relaxation factor applied to particle-particle and particle-shape contact corrections [dimensionless]. Defaults to 0.9.

  • shape_matching_relaxation (float) – Fraction of the shape-matching goal correction applied per iteration [dimensionless]. 1.0 enforces rigidity as a hard constraint. Defaults to 1.0.

  • enforce_momentum_conservation (bool) – Whether to restore the linear and angular momentum that the shape-matching projection introduces. Defaults to True.

  • inertia_regularization (float) – Tikhonov term added to each group’s inertia tensor before inverting it, as a fraction of trace(I) / 3 [dimensionless]. 0.0 (default) inverts the tensor unmodified. Raise it for groups whose particles are collinear.

  • enable_restitution (bool) – Whether to apply restitution to particle-shape contacts after the positional solve. Defaults to False.

  • deterministic (DeterministicMode | None) – Opt-in determinism for this solver’s atomic-emitting kernel modules. Pass a warp.DeterministicMode, or None (default) to inherit the current wp.config.deterministic mode.

notify_model_changed(flags)#

Refresh cached body data after model properties change.

Effective inverse masses and inertia tensors are refreshed when BODY_PROPERTIES or BODY_INERTIAL_PROPERTIES is set. Other flags are ignored; particle group changes are not covered by any flag, see rebuild_group_layout().

Parameters:

flags (ModelFlags | int) – Bitmask of ModelFlags or custom int bits indicating which model properties changed.

rebuild_group_layout()#

Rebuild the cached particle-group layout from the model.

Call this after changing newton.Model.particle_mass or newton.Model.particle_group, neither of which is covered by a ModelFlags bit.

set_rest_shape(particle_q=None)#

Capture the configuration that shape matching restores.

Parameters:

particle_q (wp.array[wp.vec3f] | None) – Rest positions [m], shape [particle_count]. If None, newton.Model.particle_q is used.

step(state_in, state_out, control, contacts, dt)#

Advance the simulation state by one time step.

Parameters:

  • state_in (State) – State at the beginning of the time step.

  • state_out (State) – State that receives the simulation result.

  • control (Control | None) – Unused; accepted for compatibility with step().

  • contacts (Contacts | None) – Contact data produced by collide(). If None, particle-shape contact handling is skipped.

  • dt (float) – Time step size [s].
